## 六、人工复核注意事项（入库前必做）
1. **全文 vs 公告**：文件名含“公告/通知/通报”的仅为发布信息，不可当条文全文切片；全文类以“全文/PDF/DOCX”标识为准。
2. **待核实项**：清单“时效状态/来源URL”为“待核实”的字段需人工补核；`建质〔2015〕206号附件DOC`内容未程序化验证，请先打开确认。
3. **地方标准原文**：闽建科〔2025〕14号附件为 84MB 官方 RAR 打包（10项标准及图集），沙箱无解压工具，请在本地解包后提取 DBJ/T13-91-2025、DBJ/T13-318-2025 原文单独入库。
4. **HTML 页保存形态**：政府网页 HTML 含导航/页脚噪声，切片前建议做正文抽取；部分页面正文字数已在清单“备注”列提示。
5. **地域适配**：05类事故案例含外省案例，仅用于警示教育语料，福建/厦门案例优先。
6. 所有资料默认“待人工审核”，经审核后方可进入生产知识库。
