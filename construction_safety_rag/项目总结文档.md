# 施工安全证据助手 RAG 项目总结

## 一、项目定位

本项目是原“嘉庚智答”RAG 的施工安全领域版本，服务于建筑施工实习场景。它与 `construction-safety-inspection` 视觉巡检系统分开运行、分开展示，不共享运行时状态；两个项目只在实习报告中形成“施工现场识别 + 安全知识检索”的并列项目关系。问答编排、会话记忆、流式 SSE、前端交互和图谱页面均沿用原项目，替换的是知识库、领域提示词和项目文案。

## 二、已经完成的链路

```text
官方法规网页/PDF
  -> 下载与清洗
  -> 条款/语义片段切分
  -> 本地向量特征 + BM25 混合检索
  -> 施工安全实体与关系图谱
  -> 原 RAGPipeline 的查询分析与检索路由
  -> Dense/BM25/实体图谱/关系图谱加权融合
  -> Evidence Judge 与有限 Query Rewrite 重试
  -> 带来源和版本状态的证据返回
  -> 流式 LLM 生成、会话历史和滚动摘要
  -> FastAPI 本地接口与原版前端
```

当前数据构建结果：

- 成功处理 18 个官方或政府公开转载来源；
- 生成 446 个知识片段；
- 生成 1456 个施工安全实体、3495 条关系；
- 原始资料位于 `data/raw/`；
- 清洗文本位于 `data/clean/`；
- 索引和图谱位于 `data/processed/`。

## 三、知识库来源

知识库来源清单位于 `data/source_catalog.json`，包括：

1. 《中华人民共和国安全生产法（2021年修正）》；
2. 《福建省建筑施工安全生产标准化评价实施细则（2022年版）》；
3. 福建省智慧工地建设试点通知；
4. 福建省进一步加强房屋市政工程安全生产工作的通知；
5. 《房屋市政工程生产安全重大事故隐患判定标准（2024版）》及其政府公开网页转载全文；
6. 《建筑施工安全检查标准》（JGJ 59-2011）公开全文；
7. 《建设工程施工现场安全防护、场容卫生及消防保卫标准》（DB11/945-2012）公开标准文本；
8. 国家标准《头部防护 安全帽》（GB 2811-2019）官方标准信息页。

抓取脚本会校验 `%PDF` 文件头。知识库目录保留 18 个可用来源；住建部重大事故隐患标准采用公开网页转载全文，不再保留无法下载的 PDF 目录记录，避免把错误响应展示成知识库资料。

## 四、主要接口

- `GET /api/health`：检查知识库是否构建完成；
- `POST /api/chat`：返回答案和引用；
- `GET /api/graph?entity=安全帽`：查看实体邻接关系，返回原图谱页面使用的 `nodes/edges`；
- `GET /api/project-info`：返回资料清单、Chunk 数量、图谱规模、切分规则和检索配置；
- `POST /api/chat/stream`：复用原项目 `RAGPipeline.query_stream`，以 SSE 输出检索状态、证据判断状态和生成 token。

网页入口为 `/`，直接复用原项目的会话列表、历史消息、流式 token、检索状态、引用来源和 Markdown 渲染；首页空状态增加示例问题和知识库概况。`/project` 单独展示原始资料链接、Chunk 切分规则、检索模型和完整 RAG 流程，`/graph` 展示知识图谱；施工安全项目只替换领域提示词和知识库数据。

## 五、AI 使用方式

项目保留 OpenAI 兼容接口。设置 `RAG_USE_LLM=true` 并配置 `.env` 后：

- `python scripts/build_kb.py --with-llm` 使用模型抽取实体和关系；
- `/api/chat` 使用模型基于证据生成风险解释和整改建议。

没有配置 API 时，系统使用规则图谱抽取和本地模板答案，保证抓取、切分、索引、检索和接口演示仍然可复现。

## 六、答辩表达

可以把本项目描述为：

> 面向建筑施工安全管理的知识图谱增强 RAG 系统。系统从国家法规、住建部文件和福建省施工安全政策中构建版本化知识库，通过语义片段切分、BM25 与本地向量混合检索、施工安全实体关系图谱和证据引用，为法规查询、隐患解释和整改建议提供可追溯答案。

## 七、已知边界

- 系统是资料检索和辅助分析工具，不代替安全员或主管部门作最终合规认定；
- 法规发生更新后，应重新运行抓取和构建命令并人工复核有效状态；
- 当前图谱默认使用规则抽取，配置模型后可切换为 AI 抽取；
- 安全帽问题现在由《建筑施工安全检查标准》与 GB 2811-2019 标准信息共同支撑，检索不到在线模型时仍会基于命中的证据生成本地兜底答案；
- 当前索引使用轻量本地向量特征，后续可替换为原项目已有的 BGE 向量模型，不需要改动 API 层。
- 切块规则为：先按句号、问号、感叹号、分号等边界切分；单个片段目标上限 650 字，跨片段保留 100 字重叠；对 PDF 中无标点的超长段落再按 650 字硬切，避免整份文件被错误地压成一个 Chunk。
