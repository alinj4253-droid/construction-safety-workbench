审读日期：2026-10-15。用户已明确授权发现逻辑问题后自主修正、无需等待确认。原型、知识源原料及旧工程业务文件保持原样；新增系统位于 frontend 与 backend。

## 现状与实施依据

六页原型只有 mock 与浏览器本地会话，没有业务 API。FastAPI 工程可以复用检索、图谱和 SSE 思路，但 api.py 直接导入目录外的 src.db、src.config，不能独立交付。视觉工程是安全帽两类检测，现有两个模型角色是分析与报告撰写，不能冒充办理与独立复核。四份规划文件属于历史背景，五页、旧状态与旧实施顺序以执行文档的六页、阶段 0—11 为准。

## 必须修正的冲突及决定

1. **知识源数量**：实际清单 74 行＝知识源目录 73 文件＋历史归档 1 文件，并非执行文档的 75。README 的“74 份有效＋1 历史”也不准确。来源登记按实际文件，不凑数；归档同一文件不重复计数。原清单 63 行缺有效 URL，原始值保留，能够核实的补充来源与审核记录。
2. **审核与效力**：清单“现行（默认待人工审核）”不等于审核通过；2022 判定标准仍有多份错误标为现行。将审核状态、法定效力、正文解析状态分开保存。只有审核确认且解析成功的资料进入普通检索；文书依据进一步限制法规类型、现行版本、适用地域和正文。导入时均待核验，核心原文完成来源、内容、版本校验后单独记录核验结果。旧 DOC 不冒充人工审核，保留待核验。
3. **签发与重复记录**：P6 输入已有 hazard_id，签发应关联并更新该隐患为重轨，不能每次新增相同隐患。source 保留发现来源，文书通过 documents 关联。签发前只写草稿、审查及操作记录，不改变隐患业务状态与统计；重复签发幂等。
4. **监控线索**：原型把待确认 AI 记录提前列入隐患，违反首要原则。种子台账中的轻轨记录使用已人工核实的历史事项，四条新的 pending 抓拍单独存在线索队列；确认时创建且仅创建一次隐患。反光衣、门禁在场人数明确为演示口径，不能从安全帽头框推出真实全场人数。
5. **流程状态**：逾期是派生标记，不覆盖状态；截止日期按上海时区当日 23:59:59。轻轨待确认→整改中→已闭环，重轨待整改→整改中→待复查→已销项；复查不合格可退回整改中并留意见。签发不等于已整改，更不能直接变为待复查。
6. **版本撤销**：撤销的是知识库管理操作，不能改变官方废止事实；已废止版本始终禁止成为新文书依据。已签发文书保留不可变事实与引用快照，后续治理不篡改历史。
7. **前端优先级**：保留六页布局、样式和导航，原型假数据、错误标准名称、复核通过、任意密码登录、虚假短信发送和固定动画必须更正。增加必要的上传、资料补全、驳回、整改反馈、复查意见控件，不另起 UI 框架。
8. **阶段依赖**：P1 需要 P3/P4 导航，P2 需要 P5 定位，P6 需要台账状态机。先实现当前阶段所需共享服务，后续页面逐阶段接入；验收跨页跳转对象与当前页功能，目标页完整业务在所属阶段验收。
9. **schema 缺漏**：补充持久化办理任务、条款、引用、文书版本、版本关系、知识库变更日志、全局审计、登录 token、整改附件、用户隔离会话。password_plain 改为加盐 PBKDF2；所有业务读写均鉴权。权限明确为安全员可办理，安全总监可查看、督办和审核资料，不伪造班组账户。
10. **双 Agent 验收**：正常流程不故意制造错误。返工场景使用明确标记的测试草稿注入，规则结果与独立复核都持久化；离线时标注两个角色为规则与模板兜底，不声称调用模型。缺责任人/期限时可人工补全后重新校验，证据不足不能签发。
11. **评测缺漏**：阶段 2 所谓 20 问只列 6 项，补齐 20 个含拒答、地域、失效与跨进程稳定性的用例；各页 API 与真实浏览器操作共同验收。外部模型首字时延记录实际值，不承诺外部服务恒定低于 3 秒。
12. **Git 基线**：根目录原先无 Git，两个旧工程各有嵌套 Git。通过显式索引旧工程真实文件建立根基线，保留旧 .git 原样，避免 gitlink 漏源码。环境、密钥、模型、大文件与运行数据不入 Git；交付中本地保留数据库与索引，并提供重建命令。
13. **API 补充**：采用用户指定 CloseAI，官方文档兼容地址 https://api.openai-proxy.org/v1；DeepSeek 与豆包 Seed 模型名称以该账户可用清单和实际连通测试为准。密钥只在被忽略的本地 .env，日志脱敏。禁止使用旧工程外部目录隐式 .env。
14. **缺少原文**：JGJ130、JGJ59、JGJ162 当前只有发布公告，不能伪造独立标准条款；脚手架问题可使用已核验 GB55034 或其他真实正文，明确缺少所问具体标准全文。RAR 尝试本地解包，失败记录；.bin 按文件魔数识别，不按扩展名盲读。
